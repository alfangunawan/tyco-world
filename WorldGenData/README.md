# WorldGenData

`osm_raw.json` adalah cache data OpenStreetMap untuk area sekitar Telkom University
(bbox S -6.9850, W 107.6255, N -6.9675, E 107.6380), dibuat oleh World Generator
(`Tyco World > World Generator > Download Data`). `osm_raw.info.json` mencatat waktu dan sumber unduhan.
